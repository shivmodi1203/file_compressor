# File Compressor

A desktop app (Windows and Linux) that reduces the size of files. Drag files or folders
into the window, pick a quality level, and click **Compress**.

| File type | What happens |
| --- | --- |
| Images (JPG, PNG, WebP, GIF, TIFF, BMP) | Re-encoded and downscaled if very large; BMP becomes PNG |
| PDF | Embedded images re-encoded/downscaled, streams recompressed, unused objects removed |
| Office (DOCX, XLSX, PPTX, ODT, ODS, ODP, EPUB) | Embedded images shrunk, container repacked at maximum compression |
| Anything else | Packed into a ZIP or 7z archive |

Originals are never modified. Output is saved as `name_compressed.ext` (next to the original
or in a folder you choose), and only if it is actually smaller.

## Run from source

Requires Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m file_compressor
```

## Build locally

PyInstaller cannot cross-compile, so build on the target OS. Results go to `release/`.

- Windows: `build_windows.bat` → `FileCompressor-<version>-windows-setup.exe` (needs
  [Inno Setup 6.3+](https://jrsoftware.org/isdl.php)) and a portable `.zip`
- Linux: `./build_linux.sh` → `FileCompressor-<version>-x86_64.AppImage` (needs
  [appimagetool](https://github.com/AppImage/appimagetool/releases) on `PATH` or in `$APPIMAGETOOL`)
  and a `.tar.gz`

## Publish a release

1. Set the version in `file_compressor/__init__.py`.
2. Commit, then tag and push: `git tag v0.2.0 && git push origin main v0.2.0`
3. GitHub Actions (`.github/workflows/release.yml`) runs the tests, builds Windows and Linux,
   and attaches the installer, AppImage and archives to a new GitHub Release.

The app name, publisher and homepage shown in the installer and licence notices come from
`file_compressor/__init__.py`. The application icon is generated by `tools/make_icon.py`.
